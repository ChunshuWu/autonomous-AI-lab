# Research brief

Study whether the fact that a sensor reading is missing can help predict the target. Start by reading the existing missing-value indicator literature; do not claim that this known idea is new. Find a narrow limitation worth investigating, such as whether a benefit survives a change in the reason readings go missing.

Use the synthetic example under examples/missing-measurements as a starting baseline. Prefer a small CPU-only test. This example scope does not authorize paid datasets, outside compute, physical experiments, or private data access. State what additional data would be needed for a real-world claim.

Available resources: the local CPU and memory. Check actual availability before choosing a test. No GPU is required for this brief. Keep files in the assigned project workspace. Read access to additional data must be added to the worker configuration.

Endpoint: one selected question, one implemented method, a fair baseline comparison, and a peer assessment. Stop there and report what the result supports, what it does not, and the best next small investment.
